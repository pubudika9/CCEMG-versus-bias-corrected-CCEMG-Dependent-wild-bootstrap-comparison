# Validation summary

The invalid result files generated by the earlier duplicated CCEMG lower endpoint have been removed from this corrected package.

The included `validation_outputs` directory is a reproducible smoke test with 100 Monte Carlo replications, 499 multiplier draws, and `N=T=50`; it is not the final 1,000-replication experiment. All six design cells completed successfully. The checks found zero cells with nonpositive interval lengths, invalid coverage probabilities, nonpositive ABC variances, or a DWB bandwidth different from one.

The smoke test verifies that:

- CCEMG confidence intervals have positive length;
- CCEMG coverage and rejection probabilities are not mechanically fixed at zero and one;
- ABC uses `l_N=1`;
- the ABC standard error satisfies the exact finite-sample-corrected covariance identity;
- the exact conditional variance and the simulation-based multiplier-draw variance are reported separately;
- both methods produce finite, ordered confidence intervals and power curves.

Run `bash run_hetero_pipeline.sh` for the full R experiment, or use the matching Python command documented in `README.md`.
